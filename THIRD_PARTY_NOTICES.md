# Third-party code

The tools include these libraries in source form and the DLLs include them compiled, except C++/WinRT, which comes
with the Windows SDK and is compiled into `EmotionHelper.exe` (the helper of the optional emotion model) only. Their
licenses are below.

|---|---|---|
| [MinHook](https://github.com/TsudaKageyu/minhook) 1.3.3 by Tsuda Kageyu | `minhook/` (one line changed by `build.ps1`, see `minhook/src/buffer.c`) | BSD 2-Clause, below |
| [Dear ImGui](https://github.com/ocornut/imgui) 1.61 by Omar Cornut | `CT_MirrorsEdge/imgui/` (with the `stb_*` headers by Sean Barrett) | MIT, below (stb: public domain / MIT) |
| [inih](https://github.com/benhoyt/inih) by Ben Hoyt | `CT_MirrorsEdge/inih/` | New BSD, below |

| [ufbx](https://github.com/ufbx/ufbx) 0.23.1 by Samuli Raivio (commit 26a482ae, unchanged) | `CT_MirrorsEdge/ufbx/` (reads the animation clips' FBX files) | MIT or public domain (Unlicense), its own choice of two; below |

Hattiwatti (template commit in `CT_MirrorsEdge/TEMPLATE_COMMIT.txt`).

The Panini projection (CAMERA > Wide fields of view) is written from the paper "Pannini: A New Projection for Rendering
Wide Angle Perspective Images" by Sharpless, Postle and German (2010).

The optional emotion model (`emotion_feel.onnx`, for GAME > Pose window > Voice > *From the voice*) is not part of the
tools' main download: it is a separate download that goes in `Cinematic Tools\EmotionModel\`. It is made from
audeering's model
[wav2vec2-large-robust-12-ft-emotion-msp-dim](https://huggingface.co/audeering/wav2vec2-large-robust-12-ft-emotion-msp-dim)
and the speech recordings of [RAVDESS](https://doi.org/10.5281/zenodo.1188976) (Livingstone and Russo, 2018), both
CC BY-NC-SA 4.0 (non-commercial), and is licensed under CC BY-NC-SA 4.0 too. Its full credits and license come with it,
in `Cinematic Tools\EmotionModel\README_EmotionModel.txt` and `LICENSE.txt`.

`tools/emotion_model/w2v2.py` (in the source only, not in any download) follows the Wav2Vec2 model code of
[Hugging Face Transformers](https://github.com/huggingface/transformers), licensed under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0).
